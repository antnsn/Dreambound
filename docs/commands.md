# Commands

Everything in Dreambound can be set in the options window (`/dream`). These chat commands are shortcuts.

`/dreambound` works everywhere `/dream` does. Commands only do something on a druid.

## Windows and help

| Command | What it does |
| --- | --- |
| `/dream` | Opens or closes the options window. `/dream options` and `/dream config` do the same. |
| `/dream help` | Lists every command in chat. |
| `/dream ignore Debuff Name` | Adds a debuff to the [cure](features/cure.html) ignore list, or removes it if it's already there. Not case sensitive. |
| `/dream ignore` | Lists the ignored debuffs. |

## Frames

| Command | What it does |
| --- | --- |
| `/dream unlock` | Unlocks all frames so you can drag and resize them. See [Frames and minimap](features/frames-and-minimap.html). |
| `/dream lock` | Locks the frames again. |
| `/dream move` | Unlocks the frames, or locks them if they are unlocked. |
| `/dream reset` | Puts every frame back in its default place and size. |
| `/dream grid` | Turns snapping to the grid on or off. |
| `/dream grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/dream minimap` | Shows or hides the minimap button. |

## Tooltips

| Command | What it does |
| --- | --- |
| `/dream explain` | Turns the [explanations](features/explanations.html) in tooltips on or off. |

Each command also works without the space, for example `/dreamunlock` or `/dreamreset`. That helps with chat setups that swallow the Enter key after a space.

Type anything else after `/dream` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/dream`.
